# 第2弾投稿ストック(リサーチ→原案→添削の3工程で作成)

`08_research_notes.md`のリサーチ結果を元に原案を作成し、`04_post_templates.md`の
投稿前チェックリストに沿って添削したもの。**添削後を実際にコピペして使う。**
原案と添削後を並べているのは、次回以降ネタを作るときの精度を上げるため。

---

### 1. あるある(矛盾した要求)

**原案**:
```
2歳児って本当に理解できないことが多くて、毎日振り回されています。
「ごはん食べる?」って聞くと「イヤ!」って言うのに、
出さないでいると今度は「食べる!」って怒ってきます。
これって他の家庭でもあるあるなんでしょうか。
```

**添削メモ**: 1行目が説明的でフックが弱い。語尾がタメ口で統一されていない(「〜でしょうか」が敬語寄り)。「振り回されています」がやや愚痴っぽく共感より疲労感が先に立つ。

**添削後(採用)**:
```
「ごはん食べる?」って聞いたら「イヤ!」って即答した娘。
じゃあ出さないでおくかと思ったら
5分後に「食べる!」って本気で怒ってきた。

これもう選択式クイズじゃなくて、
正解が存在しないゲームだと思ってる。

同じ経験してる親、絶対いるでしょ。
```

### 2. あるある(服の脱ぎ着矛盾)

**原案**:
```
うちの娘は服を脱がせようとすると「着る!」と泣き、
着せようとすると「脱ぐ!」と泣きます。
毎回どうしたらいいのか分からず困っています。
```

**添削メモ**: 「困っています」で終わると相談投稿っぽくなり、共感より心配コメントを誘発しやすい。オチと呼びかけを追加。

**添削後(採用)**:
```
娘の服、脱がせようとすると「着る!」って泣くのに
着せようとすると「脱ぐ!」って泣く。

つまり今の状態が一番嫌ってことらしい。
矛盾してるようで、実は一番シンプルな答えだった。

同じ体験した人、いいねで教えて。
```

### 3. あるある(お店で座り込み)

**原案**:
```
スーパーで娘が突然座り込んで動かなくなることがあります。
理由もわからず、周りの目も気になって大変です。
```

**添削メモ**: 「周りの目も気になって」がやや被害者的なトーンで、パパの当事者感が薄い。具体的な対処や心情の切り替えを足す。

**添削後(採用)**:
```
スーパーの真ん中で娘が突然座り込んで動かなくなる現象、
発生条件が未だに分からない。

今日はレジ前、昨日は野菜コーナー。
共通点を探るのはもう諦めた。

こうなったら深呼吸してしゃがんで
目線合わせるところから始めるのが俺のルーティン。
```

### 5. あるある(急な甘え・退行)

**原案**:
```
昨日まで自分でできていた着替えを、
今日は突然「できない、パパやって」と言い出しました。
成長したり戻ったりで大変です。
```

**添削メモ**: 「大変です」止まりで感情の解釈が浅い。「甘えたい欲求」という育児の知見を一言添えると学びのある投稿になる。

**添削後(採用)**:
```
昨日まで自分で着替えてた娘が
今日は急に「できない、パパやって」。

できるかできないかじゃなくて、
「今日は甘えたい日」ってだけなんだよな、たぶん。

成長は行ったり来たりするから面白い。
```

### 6. 便利グッズ紹介(キックバイク)

**原案**:
```
子どもの運動不足が気になったのでキックバイクを買いました。
庭で遊べるし気に入っています。おすすめです。
```

**添削メモ**: 実例テンプレの「良かったポイント」箇条書きが抜けている。ベネフィットが具体的でなく、保存を促す一言もない。

**添削後(採用)**:
```
一戸建てで庭があるなら、キックバイク買って正解だった。

良かったポイント
・ペダルがないから2歳でもすぐ乗りこなせた
・庭でひたすら往復するだけで体力を使い切ってくれる
・雨の日以外は外遊びのハードルが一気に下がった

体力有り余ってる2歳児と暮らす人、保存しといて損なし。
```

### 7. 便利グッズ紹介(ヒップシート抱っこひも)

抱っこひもを新しくしました。
ヒップシートタイプで腰が痛くならないので良いです。

**添削後(採用)**:
```
2歳になって体重も増えた娘の抱っこ、
腰が悲鳴を上げてたけどヒップシート型に変えて解決した。

良かったポイント

・コンパクトに収納できてベビーカーの下にも入る
・20kgまで対応してるので当分買い替えなくて済む

腰痛持ちのパパ、これはマジで保存して。
```

### 10. 本音・毒舌

**原案**:
```
育児は大変だけどかけがえのない時間だと思います。
でも正直、たまには一人になりたいと思うこともあります。
```

**添削メモ**: 敬語が混ざっていてトーンが崩れている。フックが弱く、最後の一言も曖昧。

**添削後(採用)**:
```
「育児はかけがえのない時間」
それはそう。

でも正直、休日にコンビニへ一人で買い物に行く5分が
1週間で一番の癒やしになってる日もある。

これ言うと「大袈裟」って言われそうだけど、
同じパパ、絶対いるでしょ。
```

### 11. 夫婦ネタ

**原案**:
```
妻と育児について話し合い、家事分担のルールを見直しました。
お互い納得できる形になって良かったです。
```

**添削メモ**: 報告調で終わっていて感情もエピソードもない。具体的な摩擦→解決の流れに書き換え。

**添削後(採用)**:
```
「言わなくても気づいてほしい」
これが夫婦間で一番揉める原因だと気づいた。

俺も妻も、相手が察してくれる前提で不満を溜めてた。

「気づいてほしいことリスト」を先に共有するだけで
驚くほど揉め事が減った。

期待するより、先に言語化する方が早い。
```

## 添削で共通して直したポイント(次回の執筆時に意識する)

1. **敬語混じりを削る**: 「〜です」「〜ます」が紛れ込むとタメ口キャラが崩れる
2. **報告で終わらせない**: 事実→気づき/オチ/問いかけの3段構成にする
3. **「大変です」「困っています」止まりにしない**: 感情の解釈やユーモアを一言足す
4. **グッズ紹介は「良かったポイント」の箇条書きを必ず入れる**: 保存されやすさに直結
5. **最後に一言、読者を巻き込む(いいね/保存/コメントの呼びかけ)を入れる**
