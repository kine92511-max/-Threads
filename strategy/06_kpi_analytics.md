# KPI設計と振り返りフォーマット

## 追うべき指標

| 指標 | 見る頻度 | 目的 |
|---|---|---|
| フォロワー増減数 | 週次 | アカウント全体の成長度合い |
| 投稿ごとのインプレッション | 投稿ごと | どのネタ・型が刺さったか |
| 保存数 | 投稿ごと | Tips系コンテンツの有用性評価 |
| いいね/コメント比率 | 投稿ごと | 共感度・議論を呼んだか |
| プロフィールへのアクセス数 | 週次 | フック・投稿からフォローへの導線評価 |

## 週次振り返りテンプレート

```
■ 期間: 20XX/XX/XX 〜 20XX/XX/XX

【全体】
フォロワー増減: +XX人
投稿数: XX本

【伸びた投稿 TOP3】
1. [投稿概要] - インプレッションXX / 保存XX / 型:○○
2. ...
3. ...

【伸びなかった投稿の傾向】
- (例)本音・毒舌型のうち共感より批判が多かったもの
- (例)投稿時間が深夜すぎたもの

【来週への改善アクション】
- (例)Tips型の比率を上げる
- (例)フックの1行目パターンを△△に寄せる
```

## 月次レビューの観点

- コンテンツ比率(あるある/Tips/エッセイ/毒舌/夫婦ネタ)は狙い通りか、伸びている型に寄せて再調整する
- ターゲット読者層(コメント・フォロワーの傾向)が当初想定とズレていないか
- 役割分担(`02_role_division.md`)がボトルネックになっていないか(投稿が滞る/ネタ切れが多い等)
