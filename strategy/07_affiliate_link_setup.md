# 楽天アフィリエイトリンクの取得手順

`affiliate_week_final.md`の14本には、リプ欄用の案内文に`[リンクを挿入]`というプレースホルダーが
入っている。ここに実際のアフィリエイトリンクを埋める作業の手順。**この作業はあなた自身が行う必要がある**
(楽天アカウントでのログイン・登録が必要なため)。

## 1. 楽天アフィリエイトに登録する(審査なし)

1. [楽天アフィリエイト公式サイト](https://affiliate.rakuten.co.jp/) にアクセス
2. 楽天ID(普段使っている楽天のアカウント)でログイン
3. 初回登録の場合、会員情報・報酬の受取方法(銀行口座 or 楽天ポイント)を入力
4. **審査なしですぐに使える**(楽天アフィリエイトは登録後即日利用可能)

## 2. サイト情報を登録する

1. マイページから「サイト・アプリ情報の登録」を開く
2. サイト種別で「Threads」または「SNS」を選択(項目名は時期により変わる場合がある)
3. アカウントURL(`https://www.threads.com/@papa_rakuiku`)とアカウント名を登録

## 3. 商品ページを探してリンクを発行する

`affiliate_week_final.md`に書かれている14の商品カテゴリ(食洗機、ヒップシート抱っこ紐、おもちゃ収納ラック…)について、それぞれ以下の手順でリンクを作る。

1. 楽天市場で該当カテゴリの商品ページを開く(実際に紹介したい商品を1つ選ぶ)
2. 商品ページのURLをコピー
3. 楽天アフィリエイトの「リンク作成」ページで、コピーしたURLを「URLを入力してリンクを作成」欄に貼り付ける
4. 「SNSリンクを取得」をクリックすると、Threads等のSNS投稿に貼りやすい短縮リンクが発行される
5. 発行されたリンクをコピーする

## 4. `affiliate_week_final.md`の`[リンクを挿入]`を置き換える

各投稿のリプ欄用案内文にある`[リンクを挿入]`を、対応する商品のリンクに差し替える。

```
気になる人はこっちからチェックしてみて。
[リンクを挿入]  pr
```

```
↓ 置き換え後

気になる人はこっちからチェックしてみて。
https://hb.afl.rakuten.co.jp/xxxxxxxx  pr
```

**「リンク」の後ろの半角スペース2つ+「pr」はそのまま残す**(`04_post_templates.md`で決めたPR表記フォーマット)。

## 5. 投稿時の運用

1. メイン投稿(リンクなし)を10:00/17:00に投稿
2. 投稿後すぐに「スレッドに追加」で、リンクを埋めたリプ欄用テキストを追記する

## 補足

- 商品は必ずしも1回きりで固定する必要はない。売れ行きや季節に応じて後から差し替えてよい
- 楽天アフィリエイトはリンク経由の購入で成果報酬が発生する(商品によって還元率が異なる)
- 2026年時点でRaCoupon(クーポン紹介機能)等の新機能も追加されているため、余裕があれば公式サイトで確認するとよい
