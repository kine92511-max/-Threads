## 火曜・夜(便利グッズ紹介型・アフィリエイト:食洗機)

```
皿洗いに毎晩30分取られて、娘の寝かしつけを妻に任せっぱなしになってた。

「食洗機って結局手洗いの方が早くない?」って正直思ってた。導入する前の自分に教えてやりたい、全然そんなことなかったぞって。

うちが使ってるのは食洗機。

良かったポイント
・スイッチ入れたら放置でOK。洗ってる間に料理の後片付けや娘のお風呂の準備を並行できる
・手洗いよりお湯の温度が高いから、油汚れの落ちも良くなった気がする
・皿洗いが「俺の担当」からほぼ消えたことで、寝かしつけを手伝う余裕が増えた

[実際の価格帯・機種名はここに差し替え]、これで十分すぎるくらいだった。もっと早く導入しておけばよかったと今は思ってる。

共働きで皿洗いに時間取られてる人、保存しといて。
気になる人はプロフィールのリンクから見てみて。

#PR #食洗機 #共働き家事
```

## 木曜・夜(便利グッズ紹介型・アフィリエイト:エコバックス/ロボット掃除機)

```
正直、掃除機をかける時間なんて共働きにはなかった。娘が起きてる時間に掃除機の音を鳴らすのも気が引けてたし、休日にまとめてやって毎回ぐったりしてた。

「掃除は俺の担当」って言えるようになったのは、ロボット掃除機のおかげだと思ってる。うちが使ってるのはエコバックスのロボット掃除機。

良かったポイント
・出社中や娘の昼寝中に勝手に掃除を終わらせてくれる。娘が起きてる時間を掃除に取られなくなった
・自動ゴミ収集ステーション付きだから、こまめにゴミパックを空にする手間もほぼいらない
・床全体はこれに任せて、階段や隙間はダイソンのコードレス掃除機で仕上げるだけの分業にしたら、休日にまとめてやってた頃よりだいぶ楽になった

平日の掃除時間が実質ゼロに近くなったのは、この家電のおかげが大きいと感じてる。

共働きで掃除に時間取れない人、保存しといて。
気になる人はプロフィールのリンクから見てみて。

#PR #ロボット掃除機 #共働き家事
```
