## 月曜

### 月・朝(分業あるある・問いかけ付き)

# 構成案: 「手伝う」じゃなくて「担当」、完全分業のリアル

- 投稿タイプ: 型1(分業・すれ違いあるある型)
- 執筆担当への引き継ぎ先: empathy-writer
- 狙う感情トリガー: 共感(「うちも同じ」)+ 賛否が分かれる会話喚起
- フック案:
  1. うちは「手伝う」んじゃなくて、担当が完全に分かれてる。
  2. 週明け、また同じことを思う。うちの家事は「分担」じゃなくて「分業」だと。
- 展開の流れ:
  1. 断定フック(手伝う/担当の違い)
  2. 具体的な分担表を提示(俺:料理・皿洗い・掃除・風呂/妻:朝の準備・送り迎え・寝かしつけ・洗濯)
  3. 17:00(妻お迎え)〜18:30(俺帰宅)の妻ワンオペ1.5時間に言及し、「これで分担と言えるのか」と言い切る
  4. 二択の問いかけで締める
- 盛り込む要素:
  - 家事分担表そのもの(01_persona.md「家事・育児の分担表」)
  - 17:00〜18:30の妻ワンオペ時間帯(01_persona.md「平日タイムスケジュール」)
- CTAの方向性: 「均等に分担派」か「得意分野で分業派」かの二択で問いかけ、リプライ誘発

### 月・夕方(本音・言い切り型)

# 構成案: 「イクメンですね」に対するモヤっと

- 投稿タイプ: 型2(本音・言い切り型)
- 執筆担当への引き継ぎ先: empathy-writer
- 狙う感情トリガー: 本音への共感/賛否両論(会話誘発)
- フック案:
  1. 「イクメンですね」、それ褒め言葉のつもりだと思うけど正直モヤっとする。
  2. 「パパすごいですね」って言われるたび、実はちょっと引っかかってる。
- 展開の流れ:
  1. 世間で正しいとされる評価(イクメン=褒め言葉)を提示
  2. 「それはそう、でも正直モヤる」と本音を言い切る
  3. 俺は「手伝ってる」のではなく料理・皿洗い・風呂を「自分の担当」としてやっているだけ、と実体験で裏付け
  4. 反発されそうな一言を添えつつ、同じモヤモヤを抱える人に共感を投げる
- 盛り込む要素:
  - 俺の担当領域(料理・皿洗い〈食洗機使用〉・掃除〈エコバックス+ダイソン〉・風呂)を「手伝いではなく担当」という文脈で使う
  - ちょうど18:00〜19:30(妻ワンオペ〜俺帰宅)の時間帯感を匂わせる
- CTAの方向性: 明確な問いかけは入れず、「同じこと思ってる人、絶対いるでしょ」という共感誘導型の締め(賛成・反対リプライを誘発)

### 月・夜(感情エッセイ型)

# 構成案: 娘の「おかえり」で溶ける一日の疲れ

- 投稿タイプ: 型5(感情エッセイ型)
- 執筆担当への引き継ぎ先: empathy-writer
- 狙う感情トリガー: 癒やし・救われた感
- フック案:
  1. 今日、18時半に玄関を開けたら娘が「おかえりー!」って走ってきた。
  2. 一条工務店の広い玄関を建てて3年、今日その意味を改めて感じた。
- 展開の流れ:
  1. 帰宅直後の具体的な一言・行動を短文+改行で描写
  2. 「たったそれだけのことなのに」で心情の変化を提示
  3. 一条工務店で家を建てて3年、アパート時代には無かった広さ・環境への感謝を軽く織り交ぜる
  4. 余韻を残す問いかけで締める
- 盛り込む要素:
  - 一条工務店で約3年前に新築、それ以前はアパート暮らしだった事実(01_persona.md「住まいの情報」)
  - 俺の帰宅時刻18:30頃(01_persona.md「平日タイムスケジュール」)
- CTAの方向性: 「みんなも子どもの『ただの日常動作』に救われたこと、ある?」という余韻型の問いかけ(保存・共感狙い、強い誘導はしない)

## 火曜

### 火・朝(分業あるある)

# 構成案: 朝は完全に妻の管轄、俺は「見送られる側」

- 投稿タイプ: 型1(分業・すれ違いあるある型)
- 執筆担当への引き継ぎ先: empathy-writer
- 狙う感情トリガー: 共感+ちょっとした気まずさ・自虐
- フック案:
  1. うちの朝、俺は正直「見送られる側」でしかない。
  2. 朝7時に家を出る俺は、娘の準備には一切関与してない。
- 展開の流れ:
  1. 断定フック(朝は妻の管轄、俺は無関与)
  2. 具体エピソード:俺は7時に出社、妻は9時までに娘を保育園へ送り届ける動線
  3. 「これは楽をしてるとも言えるし、申し訳なさもある」と言い切りつつ本音を少し覗かせる
  4. 二択の問いかけで締める
- 盛り込む要素:
  - 俺:7時頃出社/妻:9時までに保育園へ送り届け(01_persona.md「平日タイムスケジュール」)
- CTAの方向性: 「朝は完全に一方が担当派」か「朝も交代制派」かの二択問いかけ

### 火・夕方(実用Tips型)

# 構成案: 帰宅後30分で「料理・皿洗い・風呂」を回すルーティン

- 投稿タイプ: 型3(実用Tips型)
- 執筆担当への引き継ぎ先: empathy-writer
- 狙う感情トリガー: 学び・保存したくなる実用性
- フック案:
  1. 18時半帰宅から娘の風呂までを1時間半で回す、うちのルーティンはこれ。
  2. 「帰宅後バタバタ問題」、時間割を決めたら解決した。
- 展開の流れ:
  1. 悩みの断定(帰宅後の時間が足りない)
  2. 手順を箇条書きで提示(例:1.帰宅後すぐ料理開始 2.食洗機に皿を入れながら並行して風呂を沸かす 3.風呂は俺担当の日はここで入れる)
  3. 再現性を示す一言で締める
- 盛り込む要素:
  - 俺の担当:料理・皿洗い(食洗機使用)・風呂(01_persona.md「家事・育児の分担表」)
  - 18:30頃帰宅という具体的時刻(01_persona.md「平日タイムスケジュール」)
- CTAの方向性: 「保存しといて」という保存誘導型の締め(会話よりも保存数を狙う枠)

### 火・夜(便利グッズ紹介型・アフィリエイト)

# 構成案: 皿洗い30分がゼロになった、食洗機の話

- 投稿タイプ: 型4(便利グッズ紹介型・アフィリエイト)
- 執筆担当への引き継ぎ先: affiliate-writer
- 狙う感情トリガー: 悩み解決・納得感(信頼性重視)
- フック案:
  1. 皿洗いに毎晩30分取られて、娘の寝かしつけを妻に任せっぱなしになってた。
  2. 「食洗機って結局手洗いの方が早くない?」と思ってた自分に教えてやりたい。
- 展開の流れ:
  1. 困っていた具体的な失敗談(皿洗いに時間を取られ、家事の負担が俺に偏っていた/寝かしつけを妻に任せがちだった)
  2. 食洗機を導入した経緯
  3. 良かったポイントを箇条書きで提示(時短/清潔さ/夫婦どちらかに偏らなくなった、など実体験ベース)
  4. 価格感と「もっと早く知りたかった」で締め、PR表記
- 盛り込む要素:
  - 食洗機が俺の皿洗い担当の負担を下げている中心アイテムである事実(01_persona.md「使用している家電・グッズ」)
  - 俺の担当領域(料理・皿洗い・風呂)との関連づけ
- CTAの方向性: 「共働きで皿洗いに時間取られてる人、保存しといて」の保存誘導
- PR表記・リンク配置に関する申し送り: 本文末尾に必ず「#PR」等のPR表記を入れる(省略不可、景品表示法対応)。アフィリエイトリンクは本文に直接貼らず、プロフィール欄のリンク、または本投稿への「スレッドに追加」の返信に配置する方針で執筆すること。

## 水曜

### 水・朝(分業あるある)

# 構成案: 風呂当番は固定じゃない、うちの謎ルール

- 投稿タイプ: 型1(分業・すれ違いあるある型)
- 執筆担当への引き継ぎ先: empathy-writer
- 狙う感情トリガー: 共感+「うちはこう」の意見誘発
- フック案:
  1. うちの娘の風呂当番、実は固定されてない。
  2. 「今日はどっちが風呂入れる?」がうちの夜の合言葉になってる。
- 展開の流れ:
  1. 断定フック(風呂当番だけ日替わり)
  2. 他のタスクはきっちり分業なのに、風呂だけは俺と妻どちらも担当する日があるという事実を提示
  3. 「これはこれで意外とうまく回ってる」と言い切る
  4. 二択の問いかけで締める
- 盛り込む要素:
  - お風呂入れは日によって俺と妻どちらも担当する(表内に重複あり)という事実(01_persona.md「家事・育児の分担表」)
- CTAの方向性: 「うちも固定してない派」か「絶対固定してる派」かの二択問いかけ

### 水・夕方(本音・言い切り型)

# 構成案: 「家事は5:5が正義」に対する違和感

- 投稿タイプ: 型2(本音・言い切り型)
- 執筆担当への引き継ぎ先: empathy-writer
- 狙う感情トリガー: 賛否分かれる本音への反応(会話誘発、最重要枠に次ぐ強度)
- フック案:
  1. 「家事育児は5:5で分担すべき」。それはそう。でも正直、うちには当てはまらないと思ってる。
  2. 世間の「公平な分担」信仰、正直ちょっと窮屈だと思う。
- 展開の流れ:
  1. 世間の正論(5:5が公平)を提示
  2. 「それはそう」といったん認めた上で「でも正直」で本音を差し込む
  3. うちは俺=家電に頼る時短家事、妻=娘の生活リズムに直結するタスクという役割特化型で回っていることを実体験で裏付け
  4. 「これ言うと批判されそうだけど」を添えて言い切る
- 盛り込む要素:
  - 「俺=家電に頼って効率化する家事」「妻=娘の生活リズムに直結するタスク」という分業の構図(01_persona.md「このペルソナ情報から作れる新しいネタの方向性」1番)
- CTAの方向性: 明確な二択問いかけは入れず、「同じこと思ってる夫婦いるでしょ」の共感誘導で賛成・反対のリプライを狙う

- 投稿タイプ: 型5(感情エッセイ型)
- 執筆担当への引き継ぎ先: empathy-writer
- 狙う感情トリガー: しみじみとした感謝・Before/Afterの納得感
- フック案:
  1. アパート時代、娘が夜泣きするたびに壁の薄さにヒヤヒヤしてた。
  2. 一条工務店の家に住んで一番変わったのは、実は「気にしなくなったこと」だった。
- 展開の流れ:
  1. アパート時代の具体的な悩み(防音・気密性への不安)を短文で描写
  2. 一条工務店の家に引っ越してからの変化を提示
  3. 「たったそれだけのことなのに」の型で心情の変化(気を張らずに済む安心感)をまとめる

- 盛り込む要素:
  - 一条工務店で約3年前に新築、それ以前はアパート暮らしだった事実(01_persona.md「住まいの情報」)
  - Before/After比較の切り口(防音・気密性・収納量・水回りの快適さ)
- CTAの方向性: 「アパートから一戸建てで変わったこと、みんなは何かある?」という余韻型の問いかけ

- 盛り込む要素:
  - エコバックス(ロボット掃除機)が俺の掃除担当を支えるアイテムである事実(01_persona.md「使用している家電・グッズ」)

- CTAの方向性: 「共働きで掃除に時間取れない人、保存しといて」の保存誘導
