# バズる投稿テンプレート&実例

Threadsで伸びる投稿の共通点は「最初の1〜2行で立ち止まらせる」こと。
本文の続きは折りたたまれるため、**フックは1行目に全力を注ぐ**。

## 型1: あるある共感型

**構成**: 断定フック →「わかる人だけわかる」具体エピソード → 軽いオチ or 共感の呼びかけ

テンプレ:
```
[年齢帯]の子育て、○○すぎる選手権やってます。

第1位:「○○」
(具体的なエピソード2〜3行)

これもう全国の親、共感してくれると信じてる。
```

実例:
```
2歳の娘の「イヤ」の使い方、もはや呪文。

靴下履くのもイヤ
履かないのもイヤ
玄関で座り込んで「イヤ」しか言わない生き物と
毎朝パパ一人で10分向き合ってる。

これ通過儀礼って分かってても、
今日だけは膝から崩れ落ちた。

同じパパ・ママ、いいねだけでも押して…一人じゃないって思いたい。
```

## 型2: 実用Tips型

**構成**: 悩みの言語化(結論)→ 具体的な解決策(番号付き)→ 保存を促す一言

テンプレ:
```
[悩み]で毎日しんどい人へ。
うちが試して効果あった方法まとめます。

1.○○
2.○○
3.○○

全部お金かからないし今日からできるやつです。
保存して後で見返してね。
```

実例:
```
寝かしつけに1時間かかってた我が家が
15分で寝るようになった方法。

1. 寝る1時間前から部屋の照明を暖色系に落とす
2. お風呂は寝る30分前までに済ませる
3. 「今日楽しかったこと」を1つだけ聞いて寝る前ルーティン化

科学的根拠うんぬんより
"毎日同じ流れ"にしたのが一番効いた気がする。

同じ悩みの人、保存しといて損なし。
```

実例(一戸建て育児Tips):
```
一戸建てで2歳児育ててる人、
階段の対策これで事故ゼロです。

1. 階段の上下にベビーゲート設置(引っかけるだけの簡易タイプで十分)
2. 滑り止めマットは端が浮きやすいので両面テープで固定
3. リビングと階段の間に「ここから先はイヤイヤ期の子は入れない」ルールを親側で徹底

賃貸にはない「階段」というリスク、
戸建てのパパママは絶対保存しといて。
```

## 型3: 感情エッセイ型

**構成**: 印象的な一場面の切り取り → 心情の吐露 → 読者への問いかけ or 余韻

テンプレ:
```
今日、子どもが「○○」って言った。

(その瞬間の描写)

親になってから
こんなに心が動かされる瞬間が増えるとは思わなかった。

みんなは今日、どんな瞬間に泣きそうになった?
```

実例:
```
今日、保育園のお迎えで
娘が「パパ、今日は3番目に来た!」って
めちゃくちゃ得意げに報告してきた。

早く迎えに行けなかった日ほど
罪悪感でいっぱいだったのに、
本人にとってはただの「順番」でしかなかったらしい。

勝手に自分を追い詰めてたな、と気づかされた夜。

みんなも「勝手に自分を責めてた」ってこと、ある?
```

## 型4: 本音・毒舌型

**構成**: 綺麗事への違和感を提示 → 本音を短くズバッと → 最後に少しだけ優しさを残す

テンプレ:
```
「子育ては大変だけど幸せ」
それはそう。
でも今日だけ本音言っていい?

○○

これ言うと怒られそうだけど、
思ってる人絶対いるでしょ。
```

実例:
```
「イクメンですね」
それ、褒め言葉のつもりだと思うけど
正直モヤっとする。

俺は"手伝ってる"んじゃなくて
娘の親としてやるべきことをやってるだけなんだよな。

これ言うと「細かい」とか言われそうだけど、
同じこと思ってるパパ、絶対いるでしょ。

たまには本音、吐き出していいと思う。
```

## 型5: 夫婦・パートナーシップ型

**構成**: 家事育児の分担エピソード → あるある化 → 改善提案 or 共感オチ

テンプレ:
```
旦那(嫁)に「手伝おうか?」って言われるたびに思う。

これは"手伝う"じゃなくて"一緒にやる"なんだよって。

うちはこうやって解決した。
○○
```

実例:
```
妻に「今日は俺がやるから休んでて」って言うたびに
「いつも通りでいいよ」って返されるのが密かに悔しい。

"特別な日だけ頑張るパパ"じゃなくて
"普段からやってる前提のパパ"に見られたくて
半年かけて家事育児のタスクを可視化した。

うちで効果あったのは
「タスクを可視化して見えるところに貼る」だけ。
言葉で説明するより、リストを見せた方が伝わった。
```

## フック(1行目)だけのバリエーション集

- 「○歳児のこの行動、うちだけ?」
- 「これ言うと怒られそうだけど、正直に言う。」
- 「育児してて一番びっくりしたこと。」
- 「今日、子どもに救われた話をする。」
- 「○○で悩んでた頃の自分に伝えたいこと。」
- 「地味に助かってるアイテム、紹介させて。」
- 「誰にも言えなかったけど、今日だけ話す。」
