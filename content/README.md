# 投稿ストック運用フロー

1日5本、以下のスケジュールで投稿ストックを作成する。

| 時刻 | 種別 | テンプレート |
|---|---|---|
| 07:00 | 通常 | template1(あるある共感) |
| 10:00 | アフィリエイト | template2 |
| 12:00 | 通常 | template3(保存リスト) or template4(持論) |
| 17:00 | アフィリエイト | template2 |
| 21:00 | 通常 | template4(持論) or template1 |

## ファイル構成

- `templates.json` — 4種類のテンプレート定義(型と参考にした過去投稿番号)
- `schedule.json` — 時間帯とテンプレートの割り当て
- `YYYY-MM-DD.json` — その日の投稿ストック(実際の本文)

## アフィリエイト投稿(10:00・17:00)の運用フロー

1. **リサーチ担当(Claude)**が、楽天市場で売れている(ランキング上位・レビュー件数が多いなど)商品を具体的に調べ、`product_research`に商品名・商品ページURL(通常のitem.rakuten.co.jpリンク)・レビュー情報を記載して下書きを作成する。
2. `affiliate_link`は `[未取得: ユーザーが楽天アフィリエイトで取得後、ここに差し替え]` のプレースホルダーにしておく。
3. **ユーザー**が楽天アフィリエイトの管理画面で、`item_url`からアフィリエイトリンク(`a.r10.to/...`)を取得し、`affiliate_link`に差し替える。
4. リンク差し替え後、`status`を `draft_needs_affiliate_link` → `ready` に変更して投稿する。

## 注意

- リサーチはWebSearch/WebFetchによる公開情報がベース。楽天商品検索APIは現時点で未解決の認証エラー(403 REQUEST_CONTEXT_BODY_HTTP_REFERRER_MISSING)があり使用していない。解決すればリアルタイム売れ筋データに切り替え可能。
- 本文だけでは商品名・リンクを一切出さない(テンプレート②の鉄則)。2投稿目(返信)でのみ商品に触れる。
