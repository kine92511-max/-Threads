# 投稿カレンダー(週次テンプレート)

切り口の比率目安: あるある40% / Tips25% / 感情エッセイ20% / 本音・毒舌10% / 夫婦ネタ5%
(`01_account_strategy.md` のコンセプトに応じて比率は調整する)

## 週間スケジュール例(1日2投稿ペース)

| 曜日 | 朝(7-8時) | 夜(21-23時) |
|---|---|---|
| 月 | あるある投稿(週明けの憂鬱ネタ) | Tips投稿(時短家事・寝かしつけ) |
| 火 | あるある投稿 | 感情エッセイ(子どもの成長エピソード) |
| 水 | Tips投稿 | 本音・毒舌投稿 |
| 木 | あるある投稿 | 夫婦ネタ |
| 金 | あるある投稿(週末前の解放感ネタ) | 感情エッセイ |
| 土 | ゆるめの日常投稿 | 保存されやすいTipsまとめ投稿 |
| 日 | 週の振り返り・共感投稿 | 翌週への一言(フォロー導線) |

## ネタ出しチェックリスト(プランナー用)

- [ ] 直近1週間で自分/家族に起きた「あるある」を3つメモしたか
- [ ] コメント欄・DMで聞かれた質問をTips化できるか確認したか
- [ ] Threads内の関連ハッシュタグ・急上昇投稿をチェックしたか
- [ ] 感情の起伏が大きかった出来事(泣いた・笑った・怒った)を1つ拾えたか
- [ ] 直近伸びた投稿のフォーマットを再利用できないか確認したか

## ストック管理

- ライターが書いた投稿は「即投稿できる完成形」でストックしておく(最低3日分)
- 予定投稿はスプレッドシートやNotion等で「ステータス管理(ネタ出し→執筆中→完成→投稿済み)」する
