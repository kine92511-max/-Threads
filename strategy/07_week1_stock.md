# 初週投稿ストック(コピペ用)

`02_role_division.md` の工程どおり、企画→執筆をまとめて済ませた状態。
このまま`03_content_calendar.md`のスケジュールでコピペ投稿していけばいい。
（娘の言動などの具体エピソードは実際のものに差し替えて使うと精度が上がる)

## 月・朝(あるある)

```
2歳の娘の「イヤ」の使い方、もはや呪文。

靴下履くのもイヤ
履かないのもイヤ
玄関で座り込んで「イヤ」しか言わない生き物と
毎朝俺一人で10分向き合ってる。

これ通過儀礼って分かってても、
今日だけは膝から崩れ落ちた。

同じパパ・ママ、いいねだけでも押して…一人じゃないって思いたい。
```

## 月・夜(育児の工夫)

```
寝かしつけに1時間かかってたうちが
15分で寝るようになった方法。

1. 寝る1時間前から部屋の照明を暖色系に落とす
2. お風呂は寝る30分前までに済ませる
3. 「今日楽しかったこと」を1つだけ聞いて寝る前ルーティン化

科学的根拠うんぬんより
"毎日同じ流れ"にしたのが一番効いた気がする。

同じ悩みの人、保存しといて損なし。
```

## 火・朝(あるある)

```
一戸建てに住んでてよかったこと、
「泣き声を気にしなくていい」がまさかの1位。

マンション住みの頃は
娘が夜泣きするたびに壁ドン怖くて
抱っこしたまま外の廊下うろうろしてた。

今は家の中で好きなだけ歩き回れる。
これだけで育児のストレス、半分になった気がする。
```

## 火・夜(便利グッズ)

```
娘の食事、毎回床がベチャベチャで
片付けだけで心折れてたけど
これ買ってから本当にラクになった。

「シリコン製お食事マット(お皿の下に敷くやつ)」

良かったポイント
・こぼしても拭くだけで終わる
・折りたためて外食先にも持っていける
・見た目もかわいくて娘が喜んで座ってくれる

2,000円くらいで買えるし、もっと早く知りたかった。
同じ悩みの人、保存しといて。
```

## 水・朝(育児の工夫)

```
一戸建てで2歳児育ててる人、
階段の対策これで事故ゼロです。

1. 階段の上下にベビーゲート設置(引っかけるだけの簡易タイプで十分)
2. 滑り止めマットは端が浮きやすいので両面テープで固定
3. リビングと階段の間に「ここから先はイヤイヤ期の子は入れない」ルールを親側で徹底

賃貸にはない「階段」というリスク、
戸建てのパパママは絶対保存しといて。
```

## 木・朝(あるある)

```
2歳児と休日を過ごすと、
「疲れたけど楽しかった」が同時に来る。

朝から公園、昼寝せず暴れて、
夕方には俺の方が先に限界きてるのに
娘の「もう一回!」の無限ループに付き合ってる。
```


## 金・夜(便利グッズ)

```
一戸建て住みで地味に助かってるアイテム、紹介させて。

「玄関に置くベビーゲート付きの靴収納」

良かったポイント

これ置いてから玄関まわりのヒヤッと事案がゼロになった。
```

```
「今しかない」瞬間の連続でもあるんだよな。

```

## 使い方メモ

- 上から順に`03_content_calendar.md`の曜日・時間帯に当てはめて投稿するだけ
- エピソード部分(「」で囲った娘の発言など)は実際にあった出来事に差し替えると反応が伸びやすい
- 投稿後は`02_role_division.md`の「投稿・反応対応」に沿って直後30〜60分はコメント対応する
- 1週間終わったら`06_kpi_analytics.md`のフォーマットで振り返り、伸びた投稿の型を次週に多めに回す
