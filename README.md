# 育児系Threadsアカウント運用プロジェクト

Threadsの育児系アカウントをバズらせ、フォロワーを伸ばすための運用ドキュメント一式です。
既存アカウントを前提に、チームで役割分担しながら運用することを想定しています。

## ドキュメント構成

| ファイル | 内容 |
|---|---|
| [strategy/01_account_strategy.md](strategy/01_account_strategy.md) | アカウントコンセプト・ターゲット・トーン設計 |
| [strategy/02_role_division.md](strategy/02_role_division.md) | 役割分担(担当者ごとのタスクとフロー) |
| [strategy/03_content_calendar.md](strategy/03_content_calendar.md) | 投稿カレンダーと週次サイクル |
| [strategy/04_post_templates.md](strategy/04_post_templates.md) | バズりやすい投稿テンプレート・実例30本 |
| [strategy/05_growth_tactics.md](strategy/05_growth_tactics.md) | エンゲージメント・グロース施策 |
| [strategy/06_kpi_analytics.md](strategy/06_kpi_analytics.md) | KPI設計と振り返りフォーマット |

## 進め方

1. `01_account_strategy.md` でコンセプトを確定
2. `02_role_division.md` に沿って担当を割り振る
3. `04_post_templates.md` を元に週次で投稿を作成(`03_content_calendar.md`のサイクルに沿う)
4. `06_kpi_analytics.md` のフォーマットで週次振り返り
