# 投稿カレンダー(1日5投稿・固定時間帯)

1日5投稿、**投稿時間は固定**で運用する。アフィリエイト枠を10:00と17:00に置き、
非アフィリエイト枠(7:00・12:00・21:00)の間に挟む形。

## 固定スロット

| 時間 | 種別 | 型 |
|---|---|---|
| 7:00 | 非アフィリエイト | 分業・すれ違いあるある(問いかけ付き) |
| 10:00 | **アフィリエイト** | 便利グッズ紹介型(型4)または二択質問型(型6)からリサーチした型で構成 |
| 12:00 | 非アフィリエイト | 本音・言い切り型 or 実用Tips(曜日で交互) |
| 17:00 | **アフィリエイト** | 便利グッズ紹介型(型4)。10:00と別カテゴリの商品にする |
| 21:00 | 非アフィリエイト | 感情エッセイ or 実用Tips(曜日で交互) |

- 10:00と17:00のアフィリエイト2枠は、**必ずしも実体験に基づかなくてよい**。リサーチした売れ筋・トレンド商品カテゴリから、バズる型(型4・型6)に沿って構成する
- 同じ日の10:00と17:00で同じ商品・同じカテゴリを続けて出さない(飽きられるため)
- 週の中でジャンルが偏らないよう、`08_research_notes.md`等の商品カテゴリ候補をローテーションする

## アフィリエイトリンクの配置(リプライ欄)

投稿本文にはリンクを貼らない。投稿後、**「スレッドに追加」で1件返信を作り**、以下の2行構成にする。

```
1行目: 最後の訴求文(本文の締めと同じ、または要約した一言)
2行目: リンクURL  pr
```

- 2行目は「リンク」+「半角スペース2つ」+「pr」という並びで固定する
- これがPR表記(ステマ規制対応)を兼ねる。省略しない

## リプライ対応の優先順位

1. **7:00の「分業あるある+問いかけ」投稿**(会話を生む最重要枠)
2. 21:00の投稿(ゴールデンタイム)
3. 12:00の投稿
4. 10:00・17:00のアフィリエイト投稿(会話より保存/クリックが目的の枠なので優先度は下げてよい)

## ネタ出しチェックリスト

- [ ] 直近の分業・すれ違いエピソードを1つ拾えたか(俺の家事・妻のワンオペ時間など)
- [ ] 世間の「良いパパ/良いママ像」に対して一言言い切れるネタがあるか
- [ ] コメント欄・DMで聞かれた質問をTips化できるか確認したか
- [ ] 一条工務店・注文住宅ネタ(Before/After)を月に数本織り交ぜられているか
- [ ] 直近伸びた投稿(特にリプライが多かったもの)の型・問いかけ方を再利用できないか確認したか
- [ ] アフィリエイト2枠(10:00/17:00)のジャンルが直近と被っていないか確認したか

## ストック管理

- 「即投稿できる完成形」でストックしておく(目安:常に2日分=10本)
- 1日5投稿は固定運用のため、ストックが尽きそうな場合は執筆(まとめ書き)の頻度を上げて対応する
