# リプライ対応ガイドライン

`02_concept_tone_ratio.md`の方針(いいね数よりリプライ=会話の量がアルゴリズム評価に直結する)を実際の運用に落とし込むためのルール。
来たリプライにどう返信するかで、スレッドの伸びが大きく変わる。

## 基本の型:「同意/補強 → 一言だけ自分の情報 → 質問で返す」

1. **同意/補強**: 相手のコメントのノリ・トーンに合わせて肯定する(否定・訂正から入らない)
2. **一言だけ自分の情報を足す**: 長々説明しない。自分の立場を一文程度で補強する
3. **質問で締める**: 相手個人に向けた具体的な質問で終える(次の返信を引き出す)

**最重要なのは3の「質問で締める」**。ここが会話を1往復で終わらせず、スレッドを伸ばす鍵になる。
質問にすることで、コメントした本人だけでなく、他の閲覧者も「自分の場合はどうか」を書き込みやすくなり、
スレッド全体のコメント数(=Threadsが重視する評価指標)が増えやすくなる。

## 例

**コメント**: 「家事育児は5:5で分担すべき、とは微塵も思わないwww 偏在しててもいい派」

**返信**:
```
www 完全にわかる。「偏ってても回ってればいい」って堂々と言えない空気ある気がする。
うちも公平さより役割特化を選んだ感じで、それでずっとうまく回ってる。
(相手のアカウント名)さんの家はどういう分担なんですか?
```

## やってはいけない返信

- **お礼だけで終わる**(「ありがとうございます!」だけ等):会話がそこで途切れ、伸びに繋がらない
- **否定・訂正から入る**:相手が言い返しにくくなり、会話が止まりやすい。異なる意見でも「わかる部分もある」と一度受け止めてから自分の考えを添える
- **長文で説明しすぎる**:リプライは短く。長文は読まれにくく、次の返信も生まれにくい
- **質問を省略する**:同意して終わる返信は「いい話で終わった」感が出て、それ以上コメントしづらくなる

## 対応の優先順位・タイミング

- `03_content_calendar.md`のリプライ対応優先順位に沿う(朝の「分業あるある+問いかけ」投稿を最優先)
- 来たリプライにはできる限り全部返信する(返信率が評価に直結するため)
- 特に最初のコメントには早めに反応する(会話の起点になるので、ここで途切れさせない)

## 意見が対立するコメントが来た場合

- 攻撃的に否定しない。「その見方もあるよな」等、一度受け止める言葉を挟んでから自分の立場を言う
- それでも荒れそうな流れになったら、無理に続けず一区切りつける返信をして良い(炎上と会話は紙一重なため、`04_post_templates.md`のNGルールに反する展開は避ける)
