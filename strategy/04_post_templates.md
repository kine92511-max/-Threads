# 投稿テンプレート(バズる型のリサーチに基づく再設計)

`02_concept_tone_ratio.md`で決めた「いいね数よりリプライ(会話)を優先する」方針に沿って、
実際にThreadsで伸びている型・文章術をリサーチし、それを元にテンプレートを作り直した。

## リサーチで分かった原則

- **フックの型**: 冒頭で気を引く→読者の気持ちを代弁する→展開を提示する→結論を先に言う→短く解説する、という順番が基本
- **PAS法**: 問題提起 → 読者の気持ちを代弁して悩みを深掘り → 結論を先に言い切る → 短い解説、の構成は短い文字数でも成立しやすい
- **具体性が伸びを左右する**: 数字・手順・固有名詞(商品名など)を入れる
- **読みやすさ**: 100〜150字×3〜5行の改行で区切ると読まれやすい
- **リプライを増やす鉄板パターン**:
  - **質問型**(特に二択、または「経験の有無」を聞くもの)は答えやすく反応が集まりやすい
  - **失敗談**は完璧な発信より会話が生まれやすい(「完璧アカウント」は逆にリプライがつきにくい)
  - 来たリプライには全部返信するのが前提(返信率が評価に直結)

(参考: [Threadsで伸びる投稿テンプレ10選](https://note.com/nice_heron4924/n/n24b864e157ea), [Threadsでバズる！文章テクニック10選](https://akagami.blog/threadst/), [Threads運用で成果を出す法則](https://solezore.co.jp/blog/threads-unyo/))

## 表記ルール

- **ダブルクォーテーション(")は使わない**。強調・引用には「」【】『』を使う

## AIっぽさを消すルール

AIが書いた文章は「不自然に整いすぎている」ことで見抜かれる。特にアフィリエイト系(型4)で顕著になりやすいので徹底する。

- 文末のヘッジ表現(「〜と言われている」「〜と評判」等)を複数投稿で使い回さない。1本ごとに言い回しを変える
- 「良かったポイント」の箇条書きを毎回同じ形(3点・均等な長さ)にしない。投稿ごとに崩す
- 具体的でやや不完全なディテール(小さな迷い・ツッコミ・余談)を1つ入れ、完璧に整った紹介文にしない
- 「これにより」「そのため」「さらに」等の説明的な接続詞を使わない(AI文章に頻出、人間はあまり使わない)
- 一文の長さ・リズムをバラつかせる(短文と長文を混ぜる)

(参考: [AIっぽい文章の特徴って？自然な文章に改善する7つのコツ](https://mieru-ca.com/ai-seo/ai-marketing240909/), [【プロ直伝】「AIっぽい文章」の直し方](https://yosca.jp/technique/15165/))

## 型1: 分業・すれ違いあるある型(比率35%・最重要)

**構成(PAS法)**: 問題提起(フック) → 気持ちを代弁する具体エピソード → 言い切りのオチ → 二択 or 経験有無の問いかけ

テンプレ:
```
[分業・時間帯のあるある事実を一言で断定]

(具体的なエピソード2〜3行、数字や時間を入れる)

これって○○なんだよな。

みんなは[二択の質問]?
```

実例:
```
うちは「手伝う」んじゃなくて完全に担当が分かれてる。

俺:料理と皿洗いと風呂
妻:朝の準備と送り迎えと寝かしつけ

17時に妻が娘を迎えに行ってから、俺が18時半に帰るまでの1時間半、
妻は完全ワンオペになってる。

これって「分担してる」と言えるのか、実は微妙なところだと思ってる。

みんなの家は「均等に分担」派? それとも「得意分野で分業」派?
```

## 型2: 本音・言い切り型(比率20%)

**構成**: 結論を先に断定 → 世間の綺麗事への違和感 → 自分の実体験で裏付け → 賛否を問う一言

テンプレ:
```
[世間で正しいとされていること]。
それはそう。

でも正直、[本音]。

これ言うと[反発されそうな一言]だけど、
同じこと思ってる人、絶対いるでしょ。
```

実例:
```
「イクメンですね」
それ、褒め言葉のつもりだと思うけど正直モヤっとする。

俺は「手伝ってる」んじゃなくて、
料理・皿洗い・風呂を「自分の担当」としてやってるだけなんだよな。

これ言うと「細かい」って言われそうだけど、
同じモヤモヤ抱えてるパパ、絶対いるでしょ。
```

## 型3: 実用Tips型(比率20%)

**構成**: 悩みの断定 → 具体的な数字・手順(箇条書き) → 再現性を示す一言

テンプレ:
```
[悩み]、これで解決した。

1. ○○(数字・固有名詞を入れる)
2. ○○
3. ○○

○日で効果が出たから、再現性はあると思う。
保存しといて。
```

実例:
```
2歳児の「靴を履くだけで15分かかる」問題、これで解決した。

1. 朝は「どっちの靴から履く?」と2択で聞く
2. 玄関に踏み台を置いて自分で座れるようにする
3. 履けたら「3秒で履けたね」と数字で褒める

3日で朝の準備が10分短縮できた。
再現性あると思うから保存しといて。
```

## 型4: 便利グッズ紹介型(アフィリエイト・10:00/17:00固定枠)

**構成**: 悩み・あるある(失敗談 or 一般的な悩み) → 商品カテゴリの紹介 → 良かったポイント(箇条書き) → 行動喚起(リンクはリプ欄へ誘導)

**実体験は不要**。リサーチした売れ筋・トレンド商品カテゴリを元に構成してよい。ただし
「俺が使ってみて」のような**やっていない体験を断定する一人称の嘘は書かない**。
実体験がない場合は「話題になってる」「探してる人向けにまとめた」等、紹介者としての立場で書く。

テンプレ:
```
[悩み・あるある(失敗談 or 一般的な悩み)]。

「○○(商品カテゴリ)」が今、この悩みの解決策として話題になってる。

良かったポイント
・○○
・○○
・○○

気になる人はリプ欄見てみて。
```

実例(実体験ベース):
```
皿洗いに毎晩30分取られて、娘の寝かしつけを妻に任せっぱなしになってた。

食洗機を導入してから、その30分が丸ごと浮くようになった。

良かったポイント
・手洗いよりお湯の温度が高くて実は清潔
・洗ってる間に他の家事(料理の後片付け)を並行できる
・夫婦のどちらか一方に皿洗いが偏らなくなった

共働きで皿洗いに時間取られてる人、保存しといて。
気になる人はリプ欄見てみて。
```

実例(実体験不要・リサーチベース):
```
共働き2歳児家庭で今、地味にバズってるアイテムがこれ。

「ヒップシート型抱っこひも」

良かったポイント
・座面に体重が乗るから腰の負担が激減すると評判
・コンパクトに収納できてベビーカーの下にも入るタイプが人気
・20kgまで対応してるモデルなら長く使える

腰痛持ちのパパ・ママ、リプ欄見てみて。
```

- 投稿本文にはリンクを貼らない。PR表記もリンクと一緒にリプ欄に置く(下記「アフィリエイトリンクの扱い」参照)
- 10:00と17:00で同じ商品・同じカテゴリを続けて出さない

## 型5: 感情エッセイ型(比率10%)

**構成**: 短文+改行を多用したポエム的リズム → 心情の変化 → 余韻を残す問いかけ

テンプレ:
```
今日、娘が[具体的な一言・行動]。

(短い文を数行、改行を多めに)

たったそれだけのことなのに、
[自分の心情の変化]。

みんなは今日、どんな瞬間に[感情]した?
```

実例:
```
今日、娘が名前を呼ぶと
「はーい!」って全力で返事した。

たったそれだけのことなのに、
仕事で疲れて帰ってきた日にこれをやられると
一発で機嫌が直る自分がいる。

一条工務店の家を建てて3年、
アパート時代は考えられなかった広さの玄関で
毎日この瞬間を迎えられてるのはありがたい話だと思う。

みんなも子どもの「ただの日常動作」に救われたこと、ある?
```

## 型6: 二択質問型(単独投稿・リプライ最大化専用)

**構成**: 前置きなしで二択(または経験の有無)を聞く。リサーチ上、答えやすい問いが最も反応を集めやすいためあえて単独の型として持っておく。

テンプレ:
```
[テーマ]、あなたはどっち派?

A. ○○
B. ○○

理由も気軽にリプで教えて。
```

実例:
```
共働き夫婦の家事分担、どっち派?

A. 均等に半分ずつ分担する
B. 得意なことをそれぞれ担当する(不均等でもOK)

うちはBでずっとやってきたけど、理由も気軽にリプで教えて。
```

- 週1回程度、`03_content_calendar.md`の「問いかけ付き」枠にこの型をそのまま使ってもよい

## アフィリエイトリンク(楽天等)の扱い【確定フォーマット】

- **メイン投稿の本文にはリンクを貼らない**。Threadsは外部リンクを含む投稿のリーチを抑える傾向があるため
- 投稿後、**「スレッドに追加」で返信を1件作り**、以下の2行固定フォーマットで書く:

```
1行目: 最後の訴求文(本文の締めと同じ、または要約した一言)
2行目: リンクURL  pr
```

- 2行目は「リンク」+「半角スペース2つ」+「pr」の並びで固定する。これがPR表記(ステマ規制対応)を兼ねるため省略しない
- 例:
  ```
  気になる人はこっちからチェックしてみて。
  https://example.com/xxxxx  pr
  ```

## 投稿前チェックリスト

- [ ] 1行目(フック)だけで続きが気になるか
- [ ] 具体的な数字・固有名詞が入っているか(抽象的な表現だけで終わっていないか)
- [ ] 「言い切り」で終わっていて、読者が反応(賛成/反対/自分の場合)したくなるか
- [ ] 3〜5投稿に1回は明確な問いかけ(二択 or 経験の有無)で締めているか
- [ ] 医療的助言・特定の育児法への断定的批判、個人が特定される情報が入っていないか
- [ ] アフィリエイト投稿の場合、PR表記があり、本文にリンクを直接貼っていないか
- [ ] 一人称・語尾がタメ口の「俺」で統一されているか(敬語混じりがないか)
- [ ] ダブルクォーテーション(")を使っていないか。強調・引用は「」【】『』を使う
