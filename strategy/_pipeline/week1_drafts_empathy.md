# 初週投稿ドラフト(empathy-writer担当・17本)

`week1_briefs.md`のうち「引き継ぎ先: empathy-writer」指定の17本(月〜日、型1・2・3・5・6)。
火・木の型4(便利グッズ紹介・アフィリエイト)2本はaffiliate-writer担当のため対象外。

---

## 月朝

```
うちは「手伝う」んじゃなくて、担当が完全に分かれてる。

俺:料理・皿洗い・掃除・娘の風呂
妻:朝の準備・送り迎え・寝かしつけ・洗濯

17時に妻が娘を保育園に迎えに行ってから、俺が18時半に帰るまでの1時間半は、妻が完全にワンオペになってる。

正直これを「分担してる」と言っていいのか、俺自身もよくわからない。

みんなの家は「均等に分担」派? それとも「得意分野で分業」派?
```

## 月夕

```
「イクメンですね」
それ、褒め言葉のつもりだと思うけど正直モヤっとする。

俺は"手伝ってる"んじゃなくて、料理・皿洗い・娘の風呂を最初から自分の担当としてやってるだけなんだよな。

18時半に帰って、その足でキッチンに立つのも別に偉いことしてる感覚はゼロ。

これ言うと「細かいこと気にしすぎ」って言われそうだけど、同じモヤモヤ抱えてるパパ、絶対いるでしょ。
```

## 月夜

```
今日、18時半に玄関を開けたら
娘が「おかえりー!」って全力で走ってきた。

たったそれだけのことなのに、
一日分の疲れが一瞬で消えた。

一条工務店で家を建てて3年。
アパート時代の狭い玄関では、たぶんこの全力ダッシュはできなかった。

広さって、こういう瞬間のためにあったんだなと今更思う。

みんなも子どもの「ただの日常動作」に救われたこと、ある?
```

## 火朝

```
うちの朝、俺は正直「見送られる側」でしかない。

7時に家を出て出社する俺は、娘の準備には一切関与してない。

娘を9時までに保育園へ送り届けるのは全部妻の担当で、俺はその頃もう会社にいる。

楽をしてるとも言えるし、地味に申し訳なさもある。

みんなの家は「朝は完全に一方が担当」派? それとも「朝も交代制」派?
```

## 火夕

```
「帰宅後バタバタ問題」、時間割を決めたら解決した。

1. 18時半帰宅、まず米を炊飯器にセットしながら副菜を用意
2. 食洗機に洗い物を入れながら並行して湯を張る
3. 風呂は俺担当の日はこのタイミングでそのまま娘を入れる

これで帰宅から娘の風呂までの1時間半が、迷わず流れるようになった。

再現性あると思うから保存しといて。
```

## 水朝

```
うちの娘の風呂当番、実は固定されてない。

「今日はどっちが風呂入れる?」がうちの夜の合言葉になってる。

料理・皿洗い・掃除は俺、朝の準備・送り迎え・寝かしつけ・洗濯は妻、とここまではきっちり分かれてるのに、風呂だけはその日の余力で決まる。

これはこれで、意外とうまく回ってると思ってる。

みんなの家は「タスクごとに固定」派? それとも「風呂みたいに流動的」派?
```

## 水夕

```
「家事育児は5:5で分担すべき」。
それはそう。

でも正直、うちには当てはまらないと思ってる。

うちは俺が家電に頼って時短で家事を回して、妻が娘の生活リズムに直結する部分を担当する、役割特化型でずっとやってきた。

時間で割ったら5:5じゃないかもしれないけど、これがうちには一番合ってる。

これ言うと「それは妻に偏ってる」って言われそうだけど、同じやり方でうまくいってる夫婦、絶対いるでしょ。
```

## 水夜

```
アパート時代、娘が夜泣きするたびに壁の薄さにヒヤヒヤしてた。

隣の部屋に聞こえてないか、
下の階に響いてないか。

そんなことを気にしながらあやす夜が、正直しんどかった。

一条工務店の家に住んで一番変わったのは、実は「気にしなくなったこと」だった。

アパートから一戸建てで変わったこと、みんなは何かある?
```

## 木朝

```
うちの洗濯機、正直どこにボタンがあるかもうろ覚えだ。

洗う・干すは完全に妻の担当で、俺は一切ノータッチ。

その代わり料理・皿洗い・掃除・娘の風呂は俺が全部担当してる。

タスクの境界線がはっきりしてる分、お互い口出ししないで済んでるのは楽だと思う。

みんなの家は「タスクごとに完全分業」派? それとも「その都度できる方がやる」派?
```

## 木夕

```
「毎日掃除する時間がない」問題、掃除機を2台体制にしたら解決した。

1. 床全体はロボット掃除機に任せて、朝出社してる間に自動で稼働させる
2. 階段や隙間、ソファ周りはコードレス掃除機で週2〜3回だけ仕上げる
3. 念入り掃除は週末にまとめてやる日を1日だけ作る

これで平日に掃除機を手で持つ時間はほぼゼロになった。

再現性あると思うから保存しといて。
```

## 金朝

```
平日は「守り」の家事、週末は俺が「攻め」に回る。

平日は帰宅後の料理・皿洗い・娘の風呂で手一杯だけど、休日は娘と丸一日過ごして、その間に妻に休憩時間を作ってもらうようにしてる。

平日と休日で分担の形が変わるのも、うちにとっては分業のうちだと思ってる。

みんなの家は「平日も休日も分担は同じ」派? それとも「休日は分担の形を変える」派?
```

## 金夕

```
「休日は家族サービスしてます」。
それはそう。

でも正直、その言い方にちょっと引っかかる。

平日、俺は料理・皿洗い・掃除・娘の風呂を担当として回してるだけで、週末に娘と過ごすのもその延長でしかない。

「サービス」って言われると、なんだか特別なことをしてる感じになるのが違和感なんだよな。

同じモヤモヤ抱えてる人、絶対いるでしょ。

## 土夜

```

1. 食洗機:皿洗いの時間がほぼゼロになった
2. ロボット掃除機:床掃除が完全自動になった

17時〜18時半の妻ワンオペ、風呂当番が日替わりだったこと、洗濯は今週も俺は一切ノータッチだったこと。
