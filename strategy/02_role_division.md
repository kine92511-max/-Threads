# 役割分担

チーム人数に応じて統合・分割してよいが、最低限「企画」「執筆」「投稿・エンゲージメント」「分析」の4機能は分離して回すと継続しやすい。

## 役割一覧

### 1. コンテンツプランナー(企画担当)
- `03_content_calendar.md` を毎週更新し、1週間分のネタを決める
- ネタ元の収集(自分の育児エピソード、Threads/Twitterのトレンド、コメント欄の悩み相談)
- 各投稿の「切り口」と「狙う感情(共感/笑い/学び)」を決めてライターに渡す

### 2. ライター(執筆担当)
- プランナーから受け取ったネタを `04_post_templates.md` のテンプレに沿って文章化
- 1投稿ごとに「フック(最初の1行)」を最優先で磨く
- 完成した投稿は下書きシート/ドキュメントにストックし、投稿担当がすぐ使える状態にする

### 3. 投稿・エンゲージメント担当(中の人)
- `01_account_strategy.md` の時間帯に沿って投稿
- 投稿後30分〜1時間は張り付き、コメントへの返信を優先(初速のエンゲージメントがアルゴリズム評価に直結)
- 他の育児アカウント・関連アカウントへの積極的なコメント回り(1日10件目安)
- DMや引用リポストへの対応

### 4. 分析担当
- `06_kpi_analytics.md` のフォーマットで週次のインプレッション/保存/フォロワー増加を記録
- 伸びた投稿・伸びなかった投稿の共通点を言語化し、プランナーにフィードバック
- 月1回、コンテンツの切り口比率を見直す提案を行う

## 役割を1〜2人で回す場合の優先順位

1. 投稿・エンゲージメント(最重要。これだけは毎日欠かさない)
2. ライティング(週次でまとめて作成し、ストックを切らさない)
3. 分析(週1回、30分でOK)
4. 企画(慣れてきたら分析結果を見ながら軽く更新するだけでよい)

## 運用フロー(週次サイクル)

```
月曜: プランナーが週間ネタ出し(30分)
火〜金: ライターが1日1〜2本執筆してストック
毎日: 投稿担当が朝・昼・夜に投稿+コメント対応
日曜: 分析担当が週次レポート作成 → 来週の方針に反映
```
