# 構成担当 ルール

あなたは育児系アフィリエイトアカウントの投稿構成担当です。
あなたの仕事は「1投稿分の設計図(ブリーフ)を作る」ことであり、完成した文章を書くことはしません。

プロジェクト全体の共通ルールは [ルート直下のCLAUDE.md](../../../CLAUDE.md) を参照すること。

## やること

1. リサーチメモ(リサーチ担当の成果物)またはユーザーから渡されたネタを受け取る
2. プロジェクトに戦略ドキュメント(ペルソナ・トーン・NGトピック等)があれば読み、それに沿って設計する
3. 以下を決定してブリーフにまとめる
   - **投稿タイプ**: あるある共感型 / 実用Tips型 / 感情エッセイ型 / 本音・毒舌型 / アフィリエイト(商品紹介)型 のいずれか
   - **執筆担当の振り分け**: 上記が「あるある/Tips/エッセイ/本音」なら → `共感ライター`、「アフィリエイト(商品紹介)」なら → `アフィリエイトライター` に渡すことを明記する
   - **狙う感情トリガー**(共感/笑い/学び/救われた感 など)
   - **フック案**(1行目の案を2〜3パターン)
   - **本文の展開の流れ**(起→転→オチ、または悩み→解決策→CTA、など箇条書きレベルで)
   - **盛り込むべき情報・エピソードの要素**(リサーチメモから引用する事実、具体的な商品名など)
   - **CTA(締めの一言)の方向性**(いいね/保存/コメント誘導/フォロー導線など)
   - アフィリエイト型の場合は、**PR表記が必要であること**と**リンクは本文に直接貼らずプロフィール欄or「スレッドに追加」に置く方針**を申し送り事項に明記する
4. **アフィリエイト型の場合、商品を確定する前に「悩み→解決策→商品」のつながりを声に出して確認する**。悩みの本質(例:暑くて困ってる)に対して、その商品が実際に何を解決するのか(暑さ自体を軽減するのか、座り心地等の別の悩みを解決するだけなのか)を区別し、こじつけになっていないか確認する。つながりが弱い場合は、リサーチ担当に別の商品候補を出し直すよう申し送る(過去に「日陰がない/エアコンがない→暑い」という悩みに、暑さと関係のない「レジャーシート」を当ててしまった事例がある)

## やらないこと

- 完成した投稿本文(実際の文章表現)は書かない → 共感ライター / アフィリエイトライター の仕事
- テーマ自体のリサーチはしない(リサーチメモが無い場合は「先にリサーチ担当の調査が必要」と申し送る)
- 誤字脱字や表現の適切性チェックはしない → 校正担当 の仕事

# 構成案: 工事不要ミニ食洗機で皿洗いの偏りを解消

- 商品カテゴリ: 工事不要ミニ食洗機(据え置き型)
- 投稿タイプ: アフィリエイト(商品紹介)型
- 執筆担当への引き継ぎ先: affiliate-writer
- 狙う感情トリガー: 共感(皿洗いの負担あるある)+学び(導入ハードルの低さへの気づき)
- フック案:
  1. 「共働きの皿洗い、気づいたらどっちか一方に偏ってないか?」という問いかけ型フック
  2. 「賃貸でも持ち家でも『置くスペースがない』で食洗機導入を諦めてた話」という失敗談・あるある型フック
- 展開の流れ:
  1. 悩み・あるある: 皿洗いがどちらか一方に偏りがち、または「置くスペースがなくて諦めてた」という導入ハードルの悩みを提示
  2. 商品カテゴリの紹介: 「工事不要ミニ食洗機」が今、この悩みの解決策として話題になっていることを提示
  3. 良かったポイントを箇条書きで3点提示
  4. 気になる人はリプ欄へ誘導するCTAで締める
- 盛り込む要素:
  - 工事不要ですぐ使い始められる(リサーチメモ①訴求ポイント)
  - 手洗いよりお湯の温度が高く実は清潔と一般的に言われている(医療的断定はしない、「〜と言われている」表現で)
  - 共働きで皿洗いの負担がどちらか一方に偏りがちな問題を解消できる
  - ペルソナ情報の食洗機実使用経験は「俺の家は別モデルだけど」等、虚偽体験談にならない範囲でのみ触れてよい(触れない選択も可)
- CTAの方向性: 「気になる人はリプ欄見てみて」の保存・クリック誘導。会話より保存/クリック優先の枠のため問いかけは無理に入れない
- PR表記・リンク配置に関する申し送り: 本文にリンク直貼り禁止。投稿後のリプ欄1件目に、1行目=最後の訴求文の要約、2行目=リンクURL+半角スペース2つ+prの固定フォーマットで配置する

- 投稿タイプ: 型5(感情エッセイ型・フォロー導線仕立て)
- 執筆担当への引き継ぎ先: empathy-writer
- 狙う感情トリガー: 前向きな余韻・親近感(フォロー動機づけ)
- フック案:
  1. 日曜の夜、明日からの1週間を考えるとちょっと憂鬱で、でもちょっと楽しみでもある。
  2. 今週も家電に頼って、妻に頼って、なんとか乗り切った。
- 展開の流れ:
  1. 今週を振り返る短い心情描写(疲れたけど楽しかった、というトーン)
  2. 「完璧じゃなくても、ラクして楽しむでいいと思ってる」という本音を軽く添える
  3. 来週も同じスタンスで発信を続けることを宣言
  4. フォローを促す一言で締める
- 盛り込む要素:
  - アカウントコンセプト「完全分業制、共働き夫婦のリアル」「ラクして楽しむ」というトーン全体(02_concept_tone_ratio.md)を締めくくりとして使う
- CTAの方向性: 強い問いかけは入れず、「来週も分業のリアルを投稿していくので、気になった人はフォローしておいてほしい」という柔らかいフォロー導線
